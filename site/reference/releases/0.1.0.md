# 0.1.0 — interactive APK preview

DROIDLESS executes Android application DEX without Android and maps a small
framework subset to native macOS controls. This is an experimental release.

The original KasCalc 1.0 APK launches and responds to native button clicks. Its
own bytecode produced 12.0 for 7 + 5, 64.0 for 8 × 8 and 8.0 for √64. A real
[screenshot and verification record](../verification.md) document the execution.

The release adds APK/binary manifest/DEX/resource inspection, the register VM,
managed heap/GC, lifecycle, resource/layout inflation, native widgets and callbacks,
catchable Java faults, inherited interfaces/array covariance and persistent
failed-class initialization. Unsupported methods and opcodes report diagnostics.

Local validation: fmt/check, 14 Rust tests, warning-free clippy, release build,
4,096 seeded parser mutations and ten checked headless KasCalc scenarios.
No GitHub CI is used; source GitHub Actions are disabled.

```sh
git clone https://github.com/OthmaneBlial/droidless.git
cd droidless
git checkout v0.1.0
cargo build --release --locked
sh tools/fetch-kascalc.sh
target/release/droidless artifacts/apks/KasCalc.apk
```

The macOS ARM64 archive contains the CLI, license, authored Counter fixture and
hash-checked upstream fetch helper. It excludes third-party calculator binaries.
The binary is not signed with an Apple developer identity or notarized. Source
builds require Rust 1.95.0 and Apple's Command Line Tools; fixture rebuilds alone
require Android SDK tools.
The archive can be rebuilt locally with `python3 tools/package-macos.py`.

Supported scope: traditional Java Activity apps using the implemented API subset.
This is not a general Android runtime or an audited security sandbox. Storage,
Intents, timers, networking, AndroidX, Compose, JNI and JIT are not implemented.
Native mouse interaction, Counter text/key input, and lifecycle close with process
exit status 0 are proven. Full focus/IME behavior and Linux build/UI validation
remain incomplete. Use trusted APKs and read the [security boundaries](../security.md).
